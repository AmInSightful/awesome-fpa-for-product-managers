# Product Portfolio Review Template

A framework for Product Managers and Product Leaders to evaluate multiple products, features, and investments across a portfolio.

Portfolio thinking helps answer:

- Where should we invest more?
- Which products need improvement?
- Which initiatives should stop?
- How do we balance growth and profitability?

---

# Portfolio Management Framework

```
Current Performance

+

Strategic Importance

+

Future Potential

+

Investment Required

=

Portfolio Decision
```

# 4. Portfolio Prioritization Matrix

Use four categories:

```
                High Potential

                     ↑

    Invest          Scale


    Maintain        Reduce

                     ↓

                Low Potential

          Low Performance → High Performance
```

---

# 5. Investment Categories

## Scale

Products with:

- Strong growth
- High customer value
- Strong economics

Actions:

- Increase investment
- Add resources
- Accelerate roadmap

---

## Invest

Products with:

- Strategic importance
- Growth opportunity
- Improvement potential

Actions:

- Build capabilities
- Validate assumptions
- Increase focus

---

## Maintain

Products with:

- Stable performance
- Existing customer value

Actions:

- Optimize
- Improve efficiency
- Maintain quality

---

## Reduce

Products with:

- Low growth
- Low strategic value
- Weak economics

Actions:

- Reduce investment
- Sunset features
- Reallocate resources

---

# 6. BCG Matrix Analysis

Classic portfolio framework.

## Stars

High growth + high market position

Strategy:

```
Invest and scale
```

---

## Cash Cows

Low growth + strong position

Strategy:

```
Optimize profitability
```

---

## Question Marks

High growth + uncertain position

Strategy:

```
Experiment and validate
```

---

## Dogs

Low growth + weak position

Strategy:

```
Consider exit
```

# Key Takeaways

Portfolio management helps Product Leaders move from:

```
Building More Things

↓

Building The Right Things
```

The goal is not maximum output.

The goal is maximum business value.
