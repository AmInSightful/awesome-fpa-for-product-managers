# Financial Modeling

Financial modeling is the process of representing a business, product, or investment opportunity using numbers, assumptions, and formulas.

For Product Managers, financial modeling transforms ideas into measurable business cases.

It helps answer:

- Should we build this?
- How much investment is required?
- What return can we expect?
- What assumptions drive success?
- What risks exist?

---

# Why PMs Should Care

Senior Product Managers frequently make investment decisions.

Examples:

- Launching a new product
- Entering a new market
- Building an enterprise feature
- Investing in AI capabilities
- Changing pricing strategy

A financial model helps communicate:

```
Product Opportunity

↓

Investment Required

↓

Expected Business Impact

↓

Financial Return
```

---

# What Is a Financial Model?

A financial model is a structured representation of:

- Revenue assumptions
- Cost assumptions
- Growth expectations
- Investment requirements
- Business outcomes

A model typically contains:

```
Inputs

↓

Calculations

↓

Outputs

↓

Decision
```

# Three-Statement Model

The classic corporate finance model.

Connects:

```
Income Statement

+

Balance Sheet

+

Cash Flow Statement
```

Used for:

- Company valuation
- Strategic planning
- Investment decisions

---

# SaaS Financial Model

Common for software companies.

Typical structure:

```
Customers

×

Average Revenue

=

Revenue

-

Costs

=

Profitability
```

Key drivers:

- New customers
- Churn
- Expansion
- Pricing
- Gross margin

# ROI Model

ROI compares investment with expected value.

Formula:

```
ROI =

(Value Created - Investment)

/

Investment
```

Example:

Investment:

```
$1M
```

Expected return:

```
$4M
```

ROI:

```
300%
```

---

# Payback Period

Measures how quickly an investment returns its cost.

Formula:

```
Investment

/

Annual Return
```

Example:

Investment:

```
$2M
```

Annual benefit:

```
$500K
```

Payback:

```
4 years
```

---

# NPV (Net Present Value)

NPV accounts for the time value of money.

Basic idea:

A dollar today is worth more than a dollar in the future.

Used for:

- Large investments
- Infrastructure decisions
- Long-term projects

---

# Sensitivity Analysis

Shows how results change when assumptions change.

Example:

Base case:

```
Revenue:
$10M
```

What if:

```
Conversion decreases 20%?
```

or:

```
Costs increase 30%?
```

---

# Scenario Modeling

Most business decisions need multiple scenarios.

## Conservative

Lower growth assumptions.

---

## Expected

Most likely outcome.

---

## Optimistic

Strong execution.

Example:

```
Scenario      ARR

Low           $5M

Base          $10M

High          $20M
```

# Financial Model Best Practices

## Separate Inputs and Calculations

Good models clearly separate:

```
Assumptions

↓

Calculations

↓

Outputs
```

---

## Make Assumptions Visible

Every important number should have an explanation.

Example:

```
Churn Rate: 3%

Source:
Historical customer data
```

---

## Build Scenarios

Avoid relying on one prediction.

---

## Keep Models Simple

A simple model with good assumptions is better than a complex model with bad assumptions.
