# Unit Economics

Unit Economics measures the profitability and sustainability of a business at the smallest meaningful level.

For Product Managers, unit economics answers:

> "Does each customer, transaction, or usage event create value?"

A company can grow quickly and still destroy value if its unit economics are unhealthy.

---

# Why PMs Should Care

Product decisions directly influence unit economics:

| Product Decision | Economic Impact |
|---|---|
| Improve onboarding | Lower CAC |
| Increase retention | Higher LTV |
| Reduce infrastructure usage | Better margin |
| Improve pricing | Higher revenue per customer |
| Increase adoption | More expansion revenue |

---

# The Basic Unit Economics Equation

```
Value Generated

-

Cost To Serve

=

Economic Contribution
```

The goal is to maximize contribution while delivering customer value.

# Key Unit Economics Metrics

---

# Customer Lifetime Value (LTV)

LTV estimates the total value a customer generates during their relationship with a company.

Simple formula:

```
LTV =

Average Revenue Per Customer

×

Gross Margin

×

Customer Lifetime
```

Example:

```
Monthly Revenue:
$100

Gross Margin:
80%

Lifetime:
36 months

LTV:
$2,880
```

---

# Customer Acquisition Cost (CAC)

CAC measures the cost of acquiring a new customer.

Formula:

```
CAC =

Sales + Marketing Cost

/

Number of New Customers
```

Example:

```
Sales & Marketing Spend:
$500K

New Customers:
1,000

CAC:
$500
```

---

# LTV / CAC Ratio

One of the most important business health indicators.

Formula:

```
LTV

/

CAC
```

Example:

```
LTV:
$3,000

CAC:
$1,000

Ratio:
3x
```

A higher ratio indicates more efficient growth.

---

# Contribution Margin

Contribution margin shows how much value remains after variable costs.

Formula:

```
Revenue

-

Variable Costs

=

Contribution Margin
```

Variable costs include:

- Infrastructure
- Payment processing
- Delivery costs
- Customer support
- AI inference

---

# Payback Period

Measures how long it takes to recover acquisition cost.

Formula:

```
CAC

/

Monthly Contribution Margin
```

Example:

```
CAC:
$1,200

Monthly Contribution:
$100

Payback:
12 months
```

---

# Retention Economics

Retention is one of the biggest drivers of unit economics.

Higher retention creates:

- Higher LTV
- Lower acquisition pressure
- More expansion opportunities

Relationship:

```
Better Retention

↓

Longer Customer Lifetime

↓

Higher LTV

↓

Better Economics
```

# Marketplace Unit Economics

Marketplaces have unique economics.

The basic model:

```
Transaction Volume (GMV)

×

Take Rate

=

Revenue
```

Example:

```
GMV:
$10M

Take Rate:
15%

Revenue:
$1.5M
```

Costs:

- Supply acquisition
- Demand acquisition
- Payments
- Operations
- Support

---

# Marketplace Metrics

Key metrics:

## GMV

Gross Merchandise Value

Total transaction value.

---

## Take Rate

Percentage captured by marketplace.

Formula:

```
Revenue

/

GMV
```

---

## Liquidity

How easily buyers and sellers find each other.

Examples:

- Matching rate
- Time to transaction
- Availability

---

## Contribution Margin Per Transaction

Measures profitability of each transaction.

---

# Cloud Economics

Cloud products have unique cost structures.

Revenue:

```
Usage

×

Price
```

Costs:

```
Compute

+

Storage

+

Networking

+

Operations
```

Key metrics:

- Gross Margin
- Infrastructure Efficiency
- Cost Per Customer
- Cost Per Request

---

# AI Product Economics

AI introduces new cost drivers.

Traditional software:

```
More Users

≈

Low Marginal Cost
```

AI products:

```
More Usage

=

Higher Compute Cost
```

Important metrics:

- Cost per inference
- Cost per token
- Cost per request
- GPU utilization
- Model efficiency

# Unit Economics Framework for PMs

Before launching a feature:

## Customer Impact

Does it improve:

- Acquisition?
- Activation?
- Retention?
- Expansion?

---

## Revenue Impact

Does it increase:

- ARPU?
- Conversion?
- Upsell?
- Usage?

---

## Cost Impact

Does it increase:

- Infrastructure cost?
- Support cost?
- Operational complexity?

---

## Long-Term Economics

Does it improve:

- LTV?
- Margin?
- Payback period?
