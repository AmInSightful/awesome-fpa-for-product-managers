# Forecasting

Forecasting is the process of predicting future business performance using historical data, assumptions, and strategic inputs.

For Product Managers, forecasting connects:

```
Product Decisions

↓

Customer Behavior

↓

Business Drivers

↓

Future Outcomes
```

A strong PM does not only measure what happened.

They develop the ability to estimate:

- What will happen next?
- Why will it happen?
- What assumptions drive the outcome?
- What actions can change the trajectory?

---

# Why PMs Should Care About Forecasting

Product decisions often require predicting future impact:

Examples:

- How many users will adopt this feature?
- How much ARR will this initiative generate?
- How many engineers are needed?
- How much infrastructure capacity is required?
- When will an investment pay back?

Forecasting helps PMs make better decisions under uncertainty.

- Retention

```
Customers

Average Revenue Per Customer

Revenue
```

## Demand Forecasting

## Product Forecasting

Predicting product outcomes.

Examples:

- Adoption
- Usage
- Retention

- Conversion

---

## Cost Forecasting

Predicting future expenses.

Examples:

- Cloud costs
- Headcount
- Marketing spend
- Support costs

# Forecasting Approaches

---

# Top-Down Forecasting

Starts with market assumptions.

Example:

```
Total Market Size

×

Expected Market Share

=

Revenue Estimate
```

Useful for:

- New products
- Market expansion
- Strategic planning

---

# Bottom-Up Forecasting

Builds predictions from operational drivers.

Example:

```
Website Visitors

×

Conversion Rate

×

Average Order Value

=

Revenue
```

Usually more accurate for operating plans.

---

# Driver-Based Forecasting

One of the most important approaches in modern FP&A.

Instead of forecasting the outcome directly, forecast the drivers.

Example:

Instead of:

```
Revenue will grow 40%
```

Use:

```
New Customers

+

Expansion Revenue

-

Churn

=

Ending ARR
```

---

# SaaS Forecasting Model

A typical SaaS revenue model:

```
Beginning ARR

+

New ARR

+

Expansion ARR

-

Churned ARR

=

Ending ARR
```

---

# Example

Starting ARR:

```
$10M
```

New Customers:

```
+$3M
```

Expansion:

```
+$2M
```

Churn:

```
-$1M
```

Ending ARR:

```
$14M
```

---

# Cohort Forecasting

Cohort forecasting groups customers based on shared characteristics.

Examples:

- Signup month
- Industry
- Region
- Pricing tier

Example:

```
January Customers

↓

Retention Curve

↓

Future Revenue
```

Useful for:

- SaaS
- Marketplaces
- Subscription products

---

# Scenario Planning

Because the future is uncertain, companies often create multiple scenarios.

Common scenarios:

## Base Case

Most likely outcome.

---

## Best Case

Strong execution and favorable conditions.

---

## Worst Case

Unexpected challenges.

---

Example:

```
Best Case:
$20M ARR

Base Case:
$15M ARR

Worst Case:
$10M ARR
```

---

# Sensitivity Analysis

Shows how changing assumptions affects outcomes.

Example:

Question:

"What happens if churn increases?"

Model:

```
Churn +1%

↓

Lower Retention

↓

Lower ARR

↓

Lower Valuation
```

# Forecasting Workflow for PMs

## Step 1 — Define Outcome

Example:

"Increase enterprise ARR by $5M."

---

## Step 2 — Identify Drivers

Examples:

- Number of customers
- Conversion rate
- Pricing
- Retention

---

## Step 3 — Build Assumptions

Example:

```
Conversion:
5%

Pricing:
$500/month

Customers:
1,000
```

---

## Step 4 — Create Model

Calculate:

- Revenue
- Costs
- Impact

---

## Step 5 — Monitor Actual Results

Compare:

```
Forecast

vs

Actual Performance
```

❌ Not updating forecasts
