# Capital Allocation

Capital Allocation is the process of deciding where a company should invest its limited resources to maximize long-term value.

For Product Managers, capital allocation is the highest-level version of prioritization.

Instead of asking:

> "Which feature should we build?"

Leadership asks:

> "Where should the company invest its money, people, and attention?"

---

# Why PMs Should Care

Every product decision is a capital allocation decision.

Resources are limited:

- Engineering capacity
- Product teams
- Marketing budget
- Infrastructure investment
- Executive attention

Choosing one initiative means delaying or rejecting another.

---

# The Capital Allocation Framework

A simple model:

```
Available Resources

        ↓

Investment Options

        ↓

Expected Business Impact

        ↓

Risk Assessment

        ↓

Resource Allocation
```

## Improve Existing Products

## Enter New Markets

Questions:

- Market size?

# Investment Evaluation Framework

A good investment decision considers:

## Strategic Fit

Does it support company strategy?

Examples:

- Competitive advantage
- Market positioning
- Long-term vision

---

## Customer Impact

Does it create meaningful customer value?

Examples:

- Solve important problems
- Improve experience
- Increase adoption

---

## Financial Impact

Does it improve:

- Revenue
- Margin
- Efficiency
- Retention

---

## Execution Feasibility

Can we realistically deliver?

Consider:

- Team capability
- Technology complexity
- Timeline
- Dependencies

# ROI-Based Prioritization

One common approach:

```
ROI =

Expected Value

/

Investment Required
```

Example:

Initiative A:

```
Investment:
$1M

Expected Value:
$5M

ROI:
5x
```

Initiative B:

```
Investment:
$3M

Expected Value:
$6M

ROI:
2x
```

A may deserve priority.

---

# Risk-Adjusted Return

High-return projects often have higher uncertainty.

A better model:

```
Expected Value

×

Probability of Success

/

Investment
```

Example:

Project A:

```
Value:
$10M

Success Probability:
80%

Investment:
$2M
```

Risk-adjusted value:

```
$4M
```

---

# Payback Period

Measures how quickly investment returns its cost.

Formula:

```
Investment

/

Annual Benefit
```

Example:

Investment:

```
$5M
```

Annual benefit:

```
$1M
```

Payback:

```
5 years
```

---

# Opportunity Cost

One of the most important concepts.

Example:

A company has capacity for only one project:

Option A:

```
AI Platform
```

Option B:

```
Enterprise Analytics
```

Choosing A means giving up potential value from B.

# Build vs Buy vs Partner

A common capital allocation decision.

---

## Build

Use internal resources.

Advantages:

- Control
- Customization
- Strategic ownership

Disadvantages:

- Slower
- Expensive
- Maintenance burden

---

## Buy

Acquire existing capability.

Advantages:

- Faster
- Existing technology

Disadvantages:

- Integration challenges
- Vendor dependency

---

## Partner

Work with external companies.

Advantages:

- Lower investment
- Faster market entry

Disadvantages:

- Less control
