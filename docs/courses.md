# Courses

A curated collection of courses to help Product Managers build financial, analytical, strategic, and business skills.

The goal is to help PMs develop the ability to connect:

```
Product Decisions

↓

Business Metrics

↓

Financial Outcomes

↓

Strategic Impact
```

---

# How to Use This List

A Product Manager does not need to become a finance specialist.

The goal is to build enough capability to:

- Understand business performance
- Build investment cases
- Evaluate trade-offs
- Communicate with executives
- Make data-driven decisions
