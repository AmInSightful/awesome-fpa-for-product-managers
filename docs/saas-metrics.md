# SaaS Metrics

SaaS metrics help Product Managers understand whether a product is creating sustainable business value.

Unlike traditional software, SaaS businesses depend on recurring revenue, retention, expansion, and efficient growth.

A financially strong Product Manager understands not only user engagement, but also how product behavior translates into business outcomes.

---

# Why PMs Should Care About SaaS Metrics

Product decisions directly influence:

- Customer acquisition
- Activation
- Retention
- Expansion
- Revenue growth
- Cost efficiency
- Customer profitability

A feature is not successful only because users like it.

A successful feature improves one or more business outcomes:

```
More Customers

↓

More Usage

↓

Higher Retention

↓

More Revenue

↓

Higher Company Value
```

---

# SaaS Business Model Basics

A SaaS company typically grows through:

```
New Customers

+

Expansion Revenue

-

Churn

=

Ending Recurring Revenue
```

The goal is not just acquiring customers.

The goal is building a product customers continue using and paying for.

# Core SaaS Metrics

---

# ARR (Annual Recurring Revenue)

## Definition

ARR represents the predictable recurring revenue a company expects to generate annually.

Formula:

```
ARR = Monthly Recurring Revenue × 12
```

Example:

```
MRR = $500,000

ARR = $6M
```

---

## Why PMs Should Care

ARR connects product decisions to company growth.

Examples:

- Increasing adoption
- Launching premium features
- Improving retention
- Expanding accounts

---

# MRR (Monthly Recurring Revenue)

## Definition

MRR measures recurring revenue generated each month.

Common components:

```
New MRR

+

Expansion MRR

-

Churned MRR

=

Net MRR Growth
```

---

# Revenue Growth Rate

Measures how quickly recurring revenue is increasing.

Formula:

```
(New Revenue - Previous Revenue)
/
Previous Revenue
```

---

# Churn

Churn measures customers or revenue lost over time.

## Customer Churn

Percentage of customers who leave.

## Revenue Churn

Percentage of recurring revenue lost.

Example:

A company loses:

- 10 customers
- $100k ARR

Revenue churn focuses on the $100k ARR.

---

# Retention Metrics

Retention is one of the strongest indicators of product-market fit.

---

# GRR (Gross Revenue Retention)

Measures retained revenue excluding expansion.

Formula:

```
(Start ARR - Churn - Downgrades)

/

Start ARR
```

GRR answers:

> "How much revenue did we keep?"

---

# NRR (Net Revenue Retention)

Measures revenue after expansion.

Formula:

```
(Start ARR
+
Expansion
-
Churn
-
Downgrades)

/

Start ARR
```

Example:

Starting ARR:

```
$1M
```

Expansion:

```
+$200k
```

Churn:

```
-$50k
```

Ending ARR:

```
$1.15M
```

NRR:

```
115%
```

---

# CAC (Customer Acquisition Cost)

Measures the cost of acquiring a customer.

Formula:

```
Sales + Marketing Cost

/

New Customers
```

Example:

Marketing + Sales:

```
$1M
```

New Customers:

```
500
```

CAC:

```
$2,000
```

---

# LTV (Lifetime Value)

Estimates the total revenue generated from a customer.

Simple formula:

```
ARPU × Gross Margin × Customer Lifetime
```

---

# LTV / CAC Ratio

One of the most important SaaS efficiency metrics.

Formula:

```
LTV

/

CAC
```

Example:

```
LTV = $10,000

CAC = $2,500

Ratio = 4x
```

Higher ratios indicate more efficient growth.

---

# CAC Payback Period

Measures how long it takes to recover customer acquisition cost.

Formula:

```
CAC

/

Monthly Gross Profit
```

Example:

CAC:

```
$6,000
```

Monthly gross profit:

```
$500
```

Payback:

```
12 months
```

---

# Expansion Revenue

Revenue generated from existing customers.

Examples:

- Upselling
- Cross-selling
- Additional seats
- Premium features
- Usage growth

Expansion is often cheaper than acquiring new customers.

---

# Burn Multiple

Measures how efficiently a company converts cash into growth.

Formula:

```
Net Burn

/

Net New ARR
```

Example:

Burn:

```
$3M
```

New ARR:

```
$1M
```

Burn Multiple:

```
3x
```

---

# Magic Number

Measures sales efficiency.

Formula:

```
(Current Quarter ARR Growth × 4)

/

Previous Quarter Sales & Marketing Spend
```

---

# Rule of 40

A common SaaS health benchmark.

Formula:

```
Revenue Growth %

+

Profit Margin %
```

Example:

Growth:

```
50%
```

Profit Margin:

```
-5%
```

Score:

```
45%
```

A score above 40% is generally considered strong.

---

# Gross Margin

Measures how much revenue remains after delivering the product.

Formula:

```
(Revenue - Cost of Revenue)

/

Revenue
```

Typical examples:

- Software SaaS: High margin
- AI products: Lower margin due to inference costs
- Cloud products: Infrastructure dependent
