# Pricing & Monetization

Pricing is one of the highest-leverage decisions a Product Manager can influence.

A small pricing improvement can create more business value than many product improvements because pricing directly affects:

- Revenue
- Profitability
- Customer perception
- Market positioning
- Growth efficiency

Pricing is not just a finance decision.

It is a product strategy decision.

---

# Why PMs Should Care About Pricing

Product Managers influence pricing through:

- Packaging decisions
- Feature differentiation
- Value communication
- Product tiers
- Usage limits
- Premium experiences

The key question:

> "How much value does our product create, and how should we capture part of that value?"

---

# The Value Equation

A simple pricing principle:

```
Customer Value Created

>

Price Charged

>

Cost To Deliver
```

A sustainable business exists between these three points.

---

# Pricing Strategy Fundamentals

---

# Cost-Based Pricing

Price is based on production cost.

Formula:

```
Cost

+

Desired Margin

=

Price
```

Example:

Cost:

```
$50
```

Margin:

```
50%
```

Price:

```
$75
```

---

## Advantages

- Simple
- Easy to calculate

## Disadvantages

- Ignores customer value
- Can leave money on the table

---

# Competitor-Based Pricing

Price is based on market alternatives.

Example:

A SaaS company prices:

- Below competitors to gain market share
- Similar to competitors for positioning
- Above competitors for premium positioning

---

# Value-Based Pricing

The strongest pricing approach for software companies.

Price is based on customer value.

Example:

A productivity tool saves:

```
100 employee hours/month
```

Value created:

```
$10,000/month
```

Price:

```
$1,000/month
```

---

# Pricing Models

---

# Subscription Pricing

Customers pay recurring fees.

Examples:

- Monthly plans
- Annual contracts

Common metrics:

- ARR
- MRR
- Churn
- NRR

---

# Seat-Based Pricing

Price depends on number of users.

Formula:

```
Number of Users

×

Price Per User
```

Common in:

- SaaS
- Enterprise software

---

# Usage-Based Pricing

Customers pay based on consumption.

Formula:

```
Usage

×

Price Per Unit
```

Examples:

- API calls
- Storage
- Compute hours
- AI tokens

---

# Consumption-Based Pricing

Similar to usage-based pricing but focused on actual resource consumption.

Examples:

- Cloud infrastructure
- Data platforms
- AI platforms

---

# Freemium

A free product creates adoption, then converts users into paying customers.

Model:

```
Free Users

↓

Product Adoption

↓

Premium Conversion

↓

Expansion
```

Examples:

- Dropbox
- Slack
- Notion

---

# Tiered Pricing

Different packages target different customer segments.

Example:

```
Starter

↓

Professional

↓

Enterprise
```

Each tier provides increasing value.

---

# Packaging

Packaging determines:

- Which features belong together
- Which customers receive which capabilities
- How customers upgrade

Good packaging increases:

- Conversion
- Expansion
- Revenue

---

# Bundling

Combining multiple products into one offering.

Benefits:

- Higher adoption
- Increased customer value
- Reduced decision complexity

Examples:

- Microsoft 365
- AWS services
- Enterprise platforms

---

# Monetization Metrics

---

# ARPU

Average Revenue Per User.

Formula:

```
Revenue

/

Number of Users
```

---

# Average Contract Value (ACV)

Common in enterprise SaaS.

Formula:

```
Total Contract Value

/

Contract Duration
```

---

# Expansion Revenue

Revenue growth from existing customers.

Sources:

- More seats
- More usage
- New products
- Premium features

---

# Price Elasticity

Measures how demand changes when price changes.

Formula:

```
% Change in Demand

/

% Change in Price
```

Example:

If price increases 10% and demand drops only 2%:

Demand is relatively inelastic.

# Pricing Research Methods

---

# Customer Interviews

Questions:

- What problem are you solving?
- What alternatives do you use?
- What value does this create?

---

# Van Westendorp Pricing Analysis

A customer survey technique measuring:

- Too cheap
- Cheap
- Expensive
- Too expensive

---

# Conjoint Analysis

Measures customer preference between different product configurations.

Useful for:

- Packaging
- Feature prioritization
- Enterprise pricing

---

# A/B Pricing Tests

Testing different:

- Prices
- Packages
- Discounts

Measure:

- Conversion
- Revenue
- Retention

---

# Pricing Framework for PMs

Before changing pricing:

## 1. Understand Customer Value

What problem are we solving?

---

## 2. Identify Value Drivers

Examples:

- Time saved
- Revenue generated
- Cost reduced
- Risk avoided

---

## 3. Select Pricing Metric

Examples:

- User
- Usage
- Transaction
- Revenue
- Outcome

---

## 4. Design Packaging

Define:

- Free tier
- Paid tiers
- Enterprise offering

---

## 5. Measure Impact

Track:

- Conversion
- Revenue
- Retention
- Expansion

---

# Pricing Mistakes

❌ Pricing based only on cost

❌ Copying competitors

❌ Too many plans

❌ Giving away too much value

❌ Ignoring willingness to pay

❌ Changing pricing without customer research
