# Product Analytics

Product Analytics is the practice of using data to understand user behavior, measure product performance, and make better product decisions.

For Product Managers, analytics connects:

```
User Behavior

↓

Product Experience

↓

Business Outcomes

↓

Financial Impact
```

Modern PMs use analytics not only to measure usage, but to understand what drives growth, retention, and profitability.

---

# Why PMs Should Care

Product analytics helps answer:

- Are users getting value?
- Where do users drop off?
- Which features drive retention?
- Which customers are most valuable?
- What should we build next?
- Did our investment create impact?

---

# Product Analytics vs Business Analytics

## Product Analytics

Focus:

- User behavior
- Feature usage
- Customer journeys
- Product experience

Examples:

- Activation rate
- Feature adoption
- Retention

---

## Business Analytics

Focus:

- Revenue
- Costs
- Profitability
- Company performance

Examples:

- ARR
- Gross margin
- CAC

# North Star Metric

The North Star Metric represents the core value a product delivers to customers.

A good North Star Metric connects:

```
Customer Value

+

Business Growth
```

Examples:

## Airbnb

Nights booked

---

## Uber

Completed trips

---

## Spotify

Time spent listening

---

## Slack

Messages exchanged by active teams

# Acquisition Metrics

Measure how users discover and enter the product.

Common metrics:

- Visitors
- Signups
- Leads
- Conversion Rate
- Cost Per Acquisition

Formula:

```
Conversion Rate =

Conversions

/

Visitors
```

---

# Activation Metrics

Activation measures whether users experience initial value.

Examples:

- Completed onboarding
- Created first project
- Invited teammates
- Completed first transaction

A strong activation event predicts future retention.

---

# Engagement Metrics

Measure how frequently users interact with the product.

Examples:

- Daily Active Users (DAU)
- Monthly Active Users (MAU)
- Session frequency
- Feature usage
- Time spent

---

# Retention Metrics

Retention measures whether customers continue receiving value.

Common measures:

## User Retention

Percentage of users who return.

---

## Revenue Retention

Measures retained revenue.

Examples:

- GRR
- NRR

---

## Cohort Retention

Groups users by starting point.

Example:

```
January Customers

↓

Retention over 12 months
```

---

# Funnel Analysis

Funnels show where users drop off.

Example:

```
Website Visitors

↓

Signups

↓

Activated Users

↓

Paying Customers

↓

Retained Customers
```

Example:

100,000 visitors

↓

10,000 signups

↓

5,000 activated users

↓

1,000 paying customers

---

# Cohort Analysis

Cohorts compare groups over time.

Examples:

- Signup month
- Customer segment
- Pricing plan
- Industry
- Geography

Useful for:

- Retention analysis
- Product improvements
- Customer behavior

---

# Experimentation & A/B Testing

A/B testing compares different experiences.

Example:

Version A:

```
Current onboarding
```

Version B:

```
New onboarding flow
```

Measure:

- Conversion
- Activation
- Retention
- Revenue impact

---

# A/B Testing ROI

A successful experiment should not only improve metrics.

It should improve business outcomes.

Example:

New feature:

```
+10% activation
```

Question:

Does this create:

- More revenue?
- Higher retention?
- Lower costs?
