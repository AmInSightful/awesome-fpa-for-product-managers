# Templates

Templates help Product Managers apply FP&A and strategic finance concepts in real-world situations.

Instead of starting from zero, PMs can use proven structures for:

- Business cases
- Financial models
- Investment decisions
- Pricing analysis
- Product reviews
- Executive communication

A good template turns complex thinking into a repeatable process.

---

# Why PMs Should Use Finance Templates

Senior PMs frequently need to communicate:

- Why should we build this?
- How much will it cost?
- What impact will it create?
- How will we measure success?
- Should we continue investing?

Templates create consistency between:

```
Product Strategy

↓

Business Analysis

↓

Financial Impact

↓

Executive Decision
```

# SaaS Revenue Forecast Template

Use case:

Forecast future subscription revenue.

Structure:

```
Beginning ARR

+

New Customer ARR

+

Expansion ARR

-

Churned ARR

=

Ending ARR
```

Inputs:

- Customer count
- Pricing
- Growth rate
- Churn
- Expansion

Outputs:

- ARR forecast
- Revenue growth
- Retention impact

# Feature ROI Calculator

Use case:

Evaluate whether a feature investment is worthwhile.

Structure:

```
Investment

-

Engineering Cost

-

Infrastructure Cost

-

Operational Cost


=

Total Cost


Expected Value

-

Revenue Impact

-

Retention Impact

-

Cost Savings


=

Return
```

Metrics:

- ROI
- Payback period
- Strategic value
