# Contributing

First off, thank you for considering contributing to **Awesome FP&A for Product Managers**! 🎉

The goal of this repository is to become the most comprehensive and high-quality collection of FP&A, strategic finance, pricing, forecasting, financial modeling, SaaS metrics, AI, and business decision-making resources for Product Managers.

We welcome contributions from product managers, FP&A professionals, founders, finance leaders, engineers, and anyone passionate about building financially successful products.

---

## Ways to Contribute

You can contribute by:

- Adding high-quality learning resources
- Recommending books, courses, podcasts, or newsletters
- Sharing case studies
- Improving descriptions
- Fixing broken links
- Correcting mistakes
- Suggesting new categories
- Improving documentation

---

## Resource Quality Guidelines

Please only add resources that are:

- High quality and trustworthy
- Relevant to Product Managers
- Focused on business, finance, strategy, or product decision-making
- Educational rather than promotional
- Preferably free or offering significant educational value

Avoid:

- Affiliate links
- Promotional content
- Low-quality blog posts
- Duplicate resources
- AI-generated content without clear attribution

---

## Resource Format

Please use the following format:

```markdown
- **Resource Name** — Short description explaining why it's valuable.
```

Example:

```markdown
- **Financial Intelligence** — One of the best introductions to financial statements for non-finance professionals.
```

---

## Categories

If you're unsure where to add a resource, check existing categories before creating a new one.

When proposing a new category, please explain why it improves the repository.

---

## Pull Request Checklist

Before submitting a Pull Request:

- I searched for duplicates.
- The resource is relevant.
- The description is clear and concise.
- Formatting follows repository conventions.
- Markdown renders correctly.

---

## Code of Conduct

Please be respectful and constructive.

We're building a welcoming community where people can learn product finance together.

---

## Questions?

If you're unsure whether a resource belongs here, feel free to open an Issue first.

Thank you for helping make this repository better! 🚀
